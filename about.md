# xdBot

**xdBot** is a simple botting tool designed to be easy for anyone to use, intended for **showcases**.

## Features

- Basic clickbot
- Practice fixes
- Seed modifier
- Noclip
- Show trajectory
- Layout mode
- Speedhack
- Frame stepper
- Safe mode
- Renderer
- Instant respawn
- No respawn flash
- No death effect
- Macro saving and loading system
- Macro auto saving

## How to use

1. Open the menu using the **Open Menu** keybind or the button in the Pause Menu.
2. Click the **'Record'** toggle in the menu to start recording.
3. Finish a practice run of the level.
4. Play the macro by clicking the **'Play'** toggle in the menu and going into the level.
